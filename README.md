# موقع نبيل — النسخة المحلية القابلة للإدارة

## التشغيل

1. ثبّت Node.js إصدار 24 أو أحدث على جهازك.
2. فك ضغط الملفات بحيث يكون `index.html` و`server.js` وملفات CSS وJavaScript والصورة في مجلد واحد.
3. شغّل `start.bat`.
4. افتح `http://127.0.0.1:4173` للموقع، ثم افتح `http://127.0.0.1:4173/admin` لإنشاء حساب الأدمن الأساسي أول مرة.

لا توجد كلمة مرور افتراضية. أنشئ اسم المستخدم والبريد وكلمة مرور قوية من شاشة الإعداد الأولى، واحتفظ بها في مكان آمن. قاعدة البيانات تنشأ تلقائيًا داخل مجلد `data` عند أول تشغيل.

## إضافة المحتوى وتعديله

من لوحة الإدارة اختر **Add content**، ثم اختر نوع المحتوى مثل Project أو Course أو Certificate أو Article أو Video أو Service أو Experience أو Skill. املأ العنوان والوصف بالعربية والإنجليزية، ويمكنك إضافة رابط وصورة ووسوم وسعر أو مدة، ثم اختر النشر واضغط **Save content**. يظهر المحتوى المنشور على الموقع العام. تستطيع تعديله أو حذفه من قائمة المحتوى.

يمكن تعديل الاسم والنبذة والتعليم والتواصل والصورة من **Website settings**. الصورة تقبل رابطًا أو مسارًا مثل `profile.jpg`.

## ربط GitHub

من **Website settings** أدخل اسم مستخدم GitHub العام واحفظه. تُزامَن المستودعات العامة المملوكة للحساب تلقائيًا كمشاريع منشورة كل 10 دقائق، ويمكن الضغط على **Sync now** للمزامنة فورًا. لا تُستورد المستودعات الخاصة أو الـforks. لا يحتاج استيراد المستودعات العامة إلى كلمة مرور GitHub أو رمز شخصي. يتأثر التحديث بحدود GitHub للطلبات العامة؛ يمكنك مراجعة [توثيق GitHub الرسمي](https://docs.github.com/en/rest/repos/repos) و[حدود الاستخدام](https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api).

## ما يعمل الآن وما يحتاج تطويرًا إضافيًا

- يعمل الآن: موقع شخصي عربي/إنجليزي، الوضع الداكن والفاتح، صورة البروفايل المتحركة، إعداد أول حساب أدمن، تسجيل دخول، حفظ المحتوى في SQLite، إضافة وتعديل وحذف المحتوى، نشر المحتوى أو حفظه كمسودة، تعديل بيانات الموقع، ومزامنة مشاريع GitHub العامة.
- لا يحتوي هذا الإصدار بعد على حسابات العملاء والفريق، صلاحيات عدة أدمنز، رفع ملفات آمن، رسائل البريد أو واتساب، متجر، دفع إلكتروني، منصة كورسات ولايفات، تقارير مالية، أو نشر تلقائي للسوشيال. هذه مراحل لاحقة وليست أزرارًا وهمية في هذه النسخة.
- خدمة الموقع مربوطة افتراضيًا بجهازك فقط على `127.0.0.1`. لذلك لا يستطيع الآخرون الوصول إليها عبر الإنترنت حتى تُنشر على استضافة مع دومين وHTTPS وإعدادات تشغيل مناسبة. لا تغيّر `HOST` إلى `0.0.0.0` قبل إعداد الاستضافة وHTTPS ومراجعة الأمان.
- الجلسات تنتهي بعد 12 ساعة وتُسجّل داخل ذاكرة الخادم؛ إعادة تشغيل الخادم تتطلب تسجيل دخول من جديد. إذا فقدت كلمة المرور في هذه النسخة، أوقف الخدمة واستعدها عبر إجراء استعادة يدوي موثق قبل الإطلاق العام، ولا تعدّل قاعدة البيانات مباشرة إن لم تكن تعرف طريقة آمنة لذلك.

## تخزين البيانات

تُحفظ السجلات في `data/site.sqlite`. احتفظ بنسخة احتياطية من مجلد `data` عند إيقاف الموقع. لا ترفع هذا المجلد إلى مستودع GitHub عام، ولا تضع بيانات دخول الأدمن أو رموزًا سرية في الملفات.
